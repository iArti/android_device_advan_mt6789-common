# Common device configuration for Advan MT6789 family

Currently supported devices
- Tab V8 (T812)
- X1 (S34NF2)

## Evolution X build

This common tree is archived upstream; T812 development continues in
`diggieman/android_device_advan_T812`. To build Evolution X for the T812
(Android 16 QPR2 or Android 17) with one command, see [evox/README.md](evox/README.md).
